# FDFP · MIP-PPA (Modèle d'Indicateur de Performance - Produit Projet Apprentissage)
Application d'évaluation des projets de formation de type apprentissage du Fonds de Développement de la Formation Professionnelle.
Modèle MIP-PPA : 5 dimensions, 23 indicateurs, suivi à 3/6/12 mois.
PFE - ESA / INP-HB × FDFP.
Structure volontairement « à plat » (aucun sous-dossier) pour un dépôt GitHub par simple glisser-déposer.
